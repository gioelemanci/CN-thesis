\section{Notation and Conventions}
\label{app:notation}

This appendix summarizes the primary mathematical notations, graph-theoretical definitions, and physiological parameters used throughout this thesis.

\subsection{Graph Theory and Complex Networks}
\lipsum[1-2]

\begin{itemize}
    \item $G = (V, E)$: A graph defined by a set of vertices (channels/nodes) $V$ and a set of edges $E$.
    \item $N = |V|$: Total number of network nodes (channels, e.g., $N = 247$ for DB cohort and $N = 172$ for DQ cohort).
    \item $A_{ij}$: Elements of the adjacency matrix $A$, representing functional connections.
    \item $W(t)$: Dynamic functional connectivity tensor calculated via sliding-window Pearson correlation.
    \item $\mathcal{O}(t)$: Global synchronization order parameter.
    \item $S(t)$: Relative size of the giant connected component in percolation analysis.
    \item $Q(t)$: Newman modularity metric tracking community segregation.
\end{itemize}
